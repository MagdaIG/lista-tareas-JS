# lista tareas JS

Task list app built with JavaScript: add, complete and remove tasks with DOM manipulation.

## Tech Stack

JavaScript (ES6+), HTML5 and CSS3

## Getting Started

```bash
git clone https://github.com/MagdaIG/lista-tareas-JS.git
cd lista-tareas-JS
Open index.html in your browser
```
